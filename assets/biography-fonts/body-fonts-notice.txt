LXGW Neo XiHei 1.309: https://github.com/lxgw/LxgwNeoXiHei/releases/tag/v1.309
Original TTF is distributed without changes as neo-xihei.ttf.
IPA Font License Agreement 1.0: NeoXiHei-LICENSE.md
Embedding information: https://github.com/lxgw/lxgw/blob/main/documents/xizhi_embedding_instructions.md
To replace this font with the original IPA font, obtain IPAex Gothic from https://moji.or.jp/ipafont/ipafontdownload/ and replace neo-xihei.ttf in portfolio/assets/biography-fonts/ (and the distributed assets/biography-fonts/ folder). The browser aliases the file as DanniBio-NeoXiHei.
